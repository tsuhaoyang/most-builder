# MiniMOST 操作流程與邏輯範例

> 本文件與 [minimost-database-schema-design.md](minimost-database-schema-design.md) 搭配閱讀。  
> 目的：用**逐步操作**與**每個 slot 的選項／輸入值**驗證邏輯；**循環合計 TMU** 的公式與你提供的教學範例一致：  
> **合計 =（各 slot 之 TMU 加總）× `system_tmu_multiplier`（例：1）**。

### 敘事主數據與畫面分組（做法 B，2026-04-19 決議）

- **權威來源**：`work_vocab_items`（`kind`：`object` / `target`（自）/ `destination`（至）/ `hand`（手勢）等，與全系主數據一致）。
- **欄位必填性**：**物件 `object` 必填**；**自／至／手勢 選填**（API 層驗證；歷史列可允許欄位可空，由遷移策略決定）。
- **畫面編排（做法 B）**：敘事欄位**依** `minimost_sequence_slot.ui_step_group` **嵌在序列裡**（不集中在頁首）：
  - 在**取得**區塊第一格**之前**：作業物件、自、手勢（下拉，來自 `GET /api/v1/most/work-vocab/items?kind=…`）。
  - 在**放置**區塊**之前**（僅 `GM`）：**至**（`destination`）。
  - 在**移動啟動**區塊**之前**（僅 `CM`）：**至**（`destination`）。
- **儲存契約**：`POST /api/v1/minimost/cycles` 的 body 帶 `work_object_vocab_id` 與選填之 `work_from_vocab_id` / `work_to_vocab_id` / `work_hand_vocab_id`（併寫入 `minimost_motion_cycle` 與 `params_snapshot.narrative` 快照摘要）。
- **單選 UX**：B／P／X／I 等**選後其餘選項可反灰**，但**必須能再點選改選**（不鎖死點擊；反灰僅表「目前選中項」的視覺層次）。

### 動作敘事規範 (Action Narrative Protocol)

產生或顯示 MiniMOST 建模的**人讀敘事**時，**嚴禁**僅以碎片化單字、逗號斷片拼貼；須**組成結構完整、可朗讀的語句**（靜態頁或後續產生器均適用）。

#### 1. 敘事結構（每段工步的語意欄位）

| 層次 | 必須交代的語意 | 資料來源（對照） |
|------|----------------|------------------|
| **主體與起點** | 以何種**手勢**、從何處**來源**開始 | `work_hand_vocab_id`（`kind=hand`）、`work_from_vocab_id`（`kind=target`／自） |
| **取得動作** | **距離**與**身體負擔**、如何**接觸／抓取**、對象為何**物件** | 取得段 **A、B、G**；`work_object_vocab_id`（`kind=object`） |
| **放置（或依序的下一步）** | **目的地**與**放置方式／精度** | 放置前 **至**：`work_to_vocab_id`（`kind=destination`）；**P** 基底＋附加以描述方式 |

> **注**：A 在語句中轉化為「伸／移約 … 公分」等，不直接對使用者唸內部索引。B 若為 B0 可併入一句帶過；**若**非 B0，必須轉成具體身體語（如併用 `b_options.label_zh` 所代表的動作，避免只寫「B3」）。

#### 2. 語句範例

| 判定 | 例句 |
|------|------|
| **NG** | 取得 30cm，抓取，放置 10cm，丟。 |
| **Good** | 用右手從工具箱伸手約 30 公分，以接觸方式取螺絲起子，隨後移動約 10 公分，在回收桶邊以「丟入」方式完成放置。 |

（實例用詞可隨主數據 `work_vocab.name` 與表單選項自然替換。）

#### 3. 欄位到語意角色（寫作對照）

| 欄位 / 代碼 | 在完整句中扮演的角色 |
|-------------|----------------------|
| `work_vocab` **object** | 受詞（取得／放置所操作的物） |
| `work_vocab` **target**／**from**（自） | 動作起點、來源場景 |
| `work_vocab` **destination**／**to**（至） | 動作終點、目的地場景 |
| `work_vocab` **hand** | 手勢、慣用左手／右手等（以主檔用語為準） |
| **A** | 轉化為「向…處伸／移動約…公分」，不羅列代號 |
| **B** | 非 0 時寫出對應**身體**描述，不得只寫 B 階層代號 |
| **G** | 以**取得／接觸方式**的自然語**一句**帶出（可含修飾語意） |
| **P** | 以**放置主動作＋修飾**描述，必要時併**精度**語意 |

## 1. 整體操作流程（使用者／PE）

| 步驟 | 動作 | 系統行為 |
|------|------|----------|
| 1 | 選擇 **sequence model** | 僅兩種：**`GM`（一般移動）** `A B G A B P A`、**`CM`（控制移動）** `A B G M X I A`。 |
| 2 | 依 **ui_step_group** 先填**敘事**再填**該段 slot** | 取得前：object（必填）+ 自 + 手勢；`GM` 在放置前：`至`；`CM` 在移動啟動前：`至`（均為主數據 id）。 |
| 3 | 依 **slot 順序** 填寫 | 畫面依 `minimost_sequence_slot` 顯示；**以文字單選／複選為主**（參上節敘事區塊位置）。 |
| 4 | 僅在該字母需要時出現**數值** | **A**：距離；**M**：依動詞出現距離／圈數／直徑／角度／腳步距離；**X**：秒（或固定列不填）。 |
| 5 | 送出前驗證 | **G**：若該列 `requires_modifier=true`，必須勾選對應修飾；**P**：附加最多 **2** 筆；**M**：依規則組出多段 `components`，**該 slot 的 TMU = max(各段 partial_tmu)**。 |
| 6 | 儲存 **cycle** | 寫入 `minimost_motion_cycle`（含 work_vocab FK）+ 每格 `minimost_motion_cycle_slot`（`payload` + `resolved_tmu`）。 |

## 2. 各字母：互動型態、選項主表、輸入欄位

### 2.1 A（動作距離 Action Distance）

- **互動**：先**輸入距離**（建議主檔以 **cm** 存，介面可顯示 in 換算），再由 **`minimost_a_distance_band`** 對應 **index**（如 A6、A10）。  
- **本文件範例**採你教學中的對應關係（8 in ≈ 20 cm → **6**、10 in ≈ 25 cm → **10**、無移動 → **0**）。正式上線以 IE 匯入之 **MiniMOST 官方階梯** 為準。

| 輸入欄位 | 型別 | 說明 |
|----------|------|------|
| `distance_cm` | 數值（必填，除非選「不動／A0」） | 觸發距離帶與 `index_value`。 |
| 衍生 | `resolved_index_value` | 寫入 sequence 左側数字，如 6。 |
| 衍生 | `resolved_tmu` | 本設計中 **A 的貢獻＝index_value**（與你兩則教學範例的加總方式一致：直接把數字加進合計）。 |

> 若未來手冊定義「A 的數字 ≠ TMU」，則需拆欄位；目前範例依 **兩者相等** 演算。

### 2.2 B（身體動作 Body Motion）

- **互動**：**文字單選**一筆 `minimost_b_body_option`。  
- **本文件教學範例**均為 **B0**（無身體動作），故下表不展開實體 B 清單（主數據由 IE 維護）。

| 輸入欄位 | 型別 | 說明 |
|----------|------|------|
| `choice_id` | UUID | 所選一筆 body 選項。 |
| 衍生 | `resolved_index_value` / `resolved_tmu` | 如 B0 → 貢獻 **0**（與範例加總一致）。 |

### 2.3 G（取得控制 Gain Control）

- **互動**：**文字單選**一列「主要動作」；若該列需勾修飾（你表上「可選」），則在該列顯示 **checkbox**；若 `requires_modifier` 則**必填**。  
- **與 TMU**：每列一個 **G 索引數字**（下表欄位 **索引/TMU**）；**該 slot 的貢獻＝此數字**。

| 主要動作 (label) | 修飾（可選，依列顯示） | 索引 / TMU |
|------------------|------------------------|------------|
| 轻按 | □ 接触 | 3 |
| 接触 | □ 接触 | 3 |
| 轻拍 | □ 接触 | 3 |
| 抓握 | （—） | 6 |
| 抓取 | （—） | 6 |
| 重新抓握 | （—） | 6 |
| 换手 | □ 轉移 | 10 |
| 拿取 | □ 選取 | 10 |
| 拿取 | □ 選取(小) | 16 |
| 拔出 | □ 分離 | 16 |
| 拿取 | □ 收集 | 24 |

| 持久化欄位 | 說明 |
|------------|------|
| `g_action_id` | 上表之一列。 |
| `modifiers` | 如 `{ "contact": true }` / `{ "select_small": true }`，依欄定義。 |

### 2.4 P（放置 — 僅 GM 序中的 **P** 那一格）

- **互動**  
  1. **基底** `minimost_p_base_action`：**單選一列**。  
  2. **附加** `minimost_p_addon`：**多選，最多 2 個**（可 0 個）。  
- **與 TMU**  
  - 基底一個數字。  
  - 附加每勾一筆，依表 **+8 或 +16**；**對準** 若帶 `精度(<4mm)` 條件，**僅在已勾「對準」且實務上滿足精度**時才加 **+8**（邏輯上 UI 可拆成子勾選）。  

**基底（單選）**

| 動作分類 | 可選 / 方向 | 基底 TMU |
|----------|----------------|----------|
| 丟 | — | 3 |
| 保持住 | — | 3 |
| 放 | □ 無方向 | 6 |
| 放 | □ 多種方向 | 10 |
| 放 | □ 一種方向 | 16 |
| 組 | □ 多種方向 | 10 |
| 組 | □ 一種方向 | 16 |

**附加（複選，≤2）**

| 標籤 | 條件／備註 | 若入選則 ΔTMU |
|------|------------|----------------|
| 對準 | 若帶 **精度 <4mm** 條件才 +8；否則依產品定義 | +8 |
| 插入 | — | +8 |
| 較難處理 | — | +8 |
| 卡合 | — | +16 |
| 施加壓力 | — | +16 |

| 持久化欄位 | 說明 |
|------------|------|
| `base_id` | 基底列。 |
| `addon_ids` | 長度 0～2 的陣列。 |
| 衍生 | `resolved_tmu = base_tmu + sum(delta_tmu of addons)`。 |

### 2.5 M（控制移動 — 僅 **CM**）

- **互動**：一個 **M slot** 內，使用者實務上可拆解為多筆**分量**（動詞、手度、腳步等），系統分別算 **partial_tmu**，**此 slot 只取 max**。  
- **主動詞列**（節選自你方表格；有「距離階梯」者同一套 **≤1 / ≤4 / ≤10 / ≤18 / ≤30 cm (對應 2.5 / 10 / 25 / 45 / 75 等) → 3 / 6 / 10 / 16 / 24 TMU**）

| 動作 (label) | 主要輸入欄位 | 規則 / TMU |
|--------------|--------------|------------|
| 按动按钮 | 距離 (cm) | 固定 **3**（可仍記錄距離以敘事，不影響 TMU 時依主數據） |
| 理 | 距離 (cm) | 階梯：见上 |
| 穿 | 距離 (cm) | 階梯：见上 |
| 滑出螺丝 | （無階梯距離，或敘事用） | 固定 **3** |
| 推 | 距離 (cm) | 階梯：见上 |
| 拉 | 距離 (cm) | 階梯：见上 |
| 贴附 / 去除 / 撕除 / 折 / 擦拭 / 撕开 等 | 距離 (cm) | 階梯：见上 |
| 旋转 | **圈数**、**直徑 (cm)** | **直徑 ≤12.5**：1 圈 16、2 圈 32、3 圈 42；**直徑 ≤50**：1 圈 24、2 圈 42 |
| 手度 | **角度 (度)** | **≤90° → 6**；**≤180° → 10**（採上界涵義依主數據定義） |
| 脚步 | 距離 (cm) | 階梯同理；**>30 cm(75) → 42 TMU** |

**階梯（有「(距离cm)」之動詞，同一套）**

| 實測距離 d (cm) | d ≤ 1 | 1＜d ≤ 4 | 4＜d ≤ 10 | 10＜d ≤ 18 | 18＜d ≤ 30 |
|-----------------|--------|-----------|------------|-------------|-------------|
| 該段 TMU | 3 | 6 | 10 | 16 | 24 |

- **M slot 合併規則**：  
  `resolved_tmu = max( 各分量 partial_tmu )`  
  例：**理(≤4cm)→6、手度(180°)→10、腳步 0** → `max(6,10,0) = 10`。

| 持久化欄位 | 說明 |
|------------|------|
| `components[]` | 多筆 `{ verb_id, inputs, partial_tmu }`。 |
| `resolved_tmu` | 上式 max 結果。 |

### 2.6 X（處理時間 Process Time — 僅 **CM**）

| 樣板 (label_zh) | 互動 / 輸入 | 備註 |
|-----------------|------------|------|
| 并压合机台 | 時間 **S**（輸入秒） | 換算 TMU 依 `OQ-002` + `entry_mode` |
| 并卡合&压合机台 | 時間 **S** | 同上 |
| 并热熔机台 | 時間 **S** | 同上 |
| 并点胶 | 時間 **S** | 同上 |
| 并锁附固定上个序列模型目标物(锁附顺序如图所示) | 無輸入（或 0） | 固定 **0.216 s** 類列 → TMU 由系統依換算凍結 |
| 并镭雕 | 時間 **S** | 同上 |
| 刷 PPID | 無輸入 | 固定 **0.216 s** |
| 刷工单二维码 | 無輸入 | 固定 **0.216 s** |
| 刷条形码 | 無輸入 | 固定 **0.216 s** |

教學範例 **X0** 表「無機台等待／秒數為 0」→ 該 slot 貢獻 **0 TMU**（在「以索引數字加總」的演示裡寫 0）。

| 敘述（動詞 + 視野 + 對齊點） | 選取（單選一列） | TMU |

| 并确认 | □ 正常視線範圍 | 6 |

| 并对齐 | □ 正常視線範圍，到**两**点 | 16 |
| 并检查 | □ 正常視線範圍**外** | 16 |
| 并确认 | □ 正常視線範圍**外** | 16 |
| 并对准 | □ 正常視線範圍**外**，到**点** | 24 |
| 并对齐 | □ 正常視線範圍**外**，到**两**点 | 32 |

## 3. 完整範例 A — General Move（與你提供一致）

**動作情境**：伸手約 **8 in（20 cm）** 取插座蓋 → 空移約 **10 in（25 cm）** → 隨手擱置 → 無返回。

| slot | 字母 | 使用者操作／輸入 | 選項與值（精簡） | 本 slot 貢獻（加總用數字） |
|------|------|------------------|------------------|----------------------------|
| 0 | A | 輸入距離 **20 cm** | 帶出 **6** | **6** |
| 1 | B | 單選「無身體動作」等價 B0 | `index=0` | **0** |
| 2 | G | 選「抓握或抓取」一類，**6** 那一列；無需轉移／選取修飾 | 索引 **6** | **6** |
| 3 | A | 輸入 **25 cm** | 帶出 **10** | **10** |
| 4 | B | 單選 B0 | 0 | **0** |
| 5 | P | 基底選「隨手擱置、無需精確對齊」對應列（放／無精確方向，**6**） | 基底 **6**、附加 **0 個** | **6** |
| 6 | A | 選「不須返回」＝**A0** | 距離 0 → **0** | **0** |

**合計**：（6+0+6+10+0+6+0）× **1** = **28 TMU**。

**顯示字串（Sequence model 呈現）**：`A6 B0 G6 A10 B0 P6 A0`。

## 4. 完整範例 B — Controlled Move（與你提供一致）

**動作情境**：伸手 **10 in（25 cm）** 以**接觸**廢料 → 沿桌面**推 12 in（30 cm）** 入桶 → 無等待、不必精準對齊、無返回。

| slot | 字母 | 使用者操作／輸入 | 選項與值 | 本 slot 貢獻 |
|------|------|------------------|----------|--------------|
| 0 | A | **25 cm** | A → **10** | **10** |
| 1 | B | B0 | 0 | **0** |
| 2 | G | 選「單純接觸」一類（你表 **G3**） | **3** | **3** |
| 3 | M | 選動詞 **推**；輸入距離 **30 cm**（10＜d≤18 段 → **16**）；**無** 手度／腳步分量（或 0） | 僅一個分量 16，max=**16** | **16** |
| 4 | X | 樣板選「無機台處理」或**秒數 0**（與你教學 X0 一致） | **X0** | **0** |
| 5 | I | 單選「推入、不需精準對齊」→ **I0** 敘事對應的 **0** 貢獻（你範例為不對齊不檢查之 **0**） | **0** | **0** |
| 6 | A | 無返回 **A0** | **0** | **0** |

**合計**：（10+0+3+16+0+0+0）× **1** = **29 TMU**。

**顯示字串**：`A10 B0 G3 M16 X0 I0 A0`。

> **說明**：`I0` 在你敘事裡不是上表 6～32 的某一列，而是「不額外做對齊/檢查」的 **0**；產品上可訂 **i_alignment_id 特殊列「不適用/無」= 0 TMU**，與 2.7 主表並存。

## 6. 補充範例 D — P 的基底 + 2 個附加

| 項目 | 內容 |
|------|------|
| 基底 | 「放、一種方向」→ 基底 **16** |
| 附加（2 個，達上限） | 勾 **插入** +8、**施加壓力** +16 |

**該 P slot** → 16 + 8 + 16 = **40**（再 × 全循環之乘數）。

若再加第三個附加 → **應在 UI 層擋下**（與主數據「最多 2 個」一致）。

## 7. 邏輯檢核清單（給你對照用）

- [ ] **僅兩條** sequence，slot **順序固定**不可跳號。  
- [ ] **GM** 不會出現 M/X/I；**CM** 的 **P** 不出現（由序決定，不是使用者選）。  
- [ ] **A/B** 的數值來自主數據階梯；**教學數字**與兩則 28/29 範例一致。  
- [ ] **G、P 基底、I 單列** 皆為一個索引／TMU 進加總。  
- [ ] **P 附加** ≤2，且 ΔTMU 可累加（對準的 +8 是否生效依精度旗標，見 2.4）。  
- [ ] **M** 永遠先算分量再 **max**，再與其他 slot 相加。  
- [ ] **X** 要嘛填秒→換算 TMU，要嘛固定 0.216s 列，要嘛 0；與 28/29 範例的 **X0=0** 不衝突。  
- [ ] 全案再乘 **system_tmu_multiplier**。
