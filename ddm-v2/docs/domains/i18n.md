# 領域索引：i18n — 雙語 UI／資料標籤與錯誤信封

## 一句話
UI 外殼與業務資料標籤的雙語（含引擎敘事英文化）、單一錯誤信封；語言來源＝使用者個人設定，API 回應語言中立。

## 吃哪些欄位／狀態
- **`locale.py` 值域**：`Locale = Literal["zh-TW", "en"]`；`SUPPORTED_LOCALES = get_args(Locale)`；`DEFAULT_LOCALE = "zh-TW"`；欄位後綴對照 `zh-TW→_zh`、`en→_en`（**唯一衍生處**，前後端值域必須逐字相同，ADR-032 I6；前端對照見 `shared/i18n/i18n.ts` 的 `SUPPORTED_LOCALES`）。
- **錯誤 catalog**：`errors/registry.py` 的 `ErrorCode` Enum（46 碼）→ `error_handlers.py` 產出單一 `{error:{code,message,detail}}` 信封；前端 `errors.<CODE>[.<resource>]` catalog（`ErrorCatalog` 型別涵蓋全部 code）。
- 資料標籤：`label_en`／`sentence_text_en` 加法欄（7 表 clone 路徑帶英文）；`app_users.locale`。
- 前端：`t()`／`useRowNarr` 產物**不入 store**；zh-TW／en key 集合對稱（Widen typecheck）。
