📖 操作手冊 — MOST Workbench

        
      

      


        

          
這套系統在做什麼

          
MOST（Maynard Operation Sequence Technique）把每道工序拆成標準動作單元，算出客觀工時 TMU（1 TMU = 0.036 秒）。Level System 則描述工序之間的關係與限制（先後、同站、不可拆、可挪動），交給 LB（線平衡）系統用演算法算出最佳分站。

          
流程：① 建工時表算 TMU → ② 標 Level 關係 → ⑤ 版本發布 → ⑥ 匯出給 LB。

        


        

          
① WI 工時表

          
用「句子填空」描述一條動作 cycle，引擎即時算 TMU。兩種模型：

          
    
            
  • GM 一般移動（徒手取放）：七格 A B G A B P A
    • 
            
  • CM 控制移動（受控/機器動作）：七格 A B G M X I A
    • 
          

          
格意義說明

            
A移動/伸手取 reach/twist/foot 三者最大；距離分級給分

            
B身體動作彎腰/起身等（0 / 10 / 32 / 42）

            
G取得抓握/接觸/拿取…；部分需修飾子，否則歸 0

            
P放置（GM）放/組/保持 + 附加（對準需勾「精準」）

            
M控制移動（CM）推/拉/旋轉/鎖附…；依種類用距離/角度/直徑+圈數/固定計價

            
X製程時間（CM）熱壓/測試/掃描等；連續＝輸入秒數，固定＝定值

            
I對準/檢查（CM）對準、檢查動作分級

          

          
TMU = 各格指數總和 × 倍率。次數＝該動作重複次數；SIMO 群組＝同群動作同時進行（合計取群組最大值，不重複累加）。

        


        

          
② Level System（工序關係）

          
把工時表的列拖進群組盒來標關係。系統自動管 main/order，免手填。

          
概念意義對 LB

            
main / 主序頂層先後順序（precedence）先後約束

            
sub（藍盒）可移動子序：整組可挪動，內部順序固定可整組搬站

            
cub（橘盒）同站不可拆：成員必須在同一工站強制同站

            
巢狀（盒中盒）sub 內可再開 cub（sub ⊃ cub）深度限制

            
nb 約束不可同站：每站最多 N 個（逼分站）分離約束

          

          
變動主序（自由度，給 LB 挪動空間）：

          
    
            
  • 2 ＝ 固定在第 2 位（硬約束）
    • 
            
  • 1~2 ＝ 範圍：可放 1 或 2（LB 自行擇優）
    • 
            
  • 1/3 ＝ 列舉：只能 1 或 3（跳過 2）
    • 
          

          
操作：勾不到——改用拖曳把卡片拖進盒子即分組；sub 盒右上「＋ cub 子群組」做巢狀；「解散」拆組；下方紅色約束區勾卡片設「不可同站」。系統會自動檢查群組設定是否正確。

        


        

          
③ 主數據（詞彙庫）

          
管理工序用的詞彙（物件/元件/器具/從/到/手勢）。這裡新增的詞彙，立即出現在 ① 的下拉選單。日後可改由外部系統（PLM/MES）供應。

        


        

          
④ Rule-set 管理

          
TMU 的計算規則（各格分值/動詞/階梯表）是版本化的資料，由單一引擎讀取。流程：clone 成 draft → 編輯 → 發布。改規則即改全系統算出的 TMU（單一真相，不漂移）。

        


        

          
⑤ SOP 版本

          
工序單以版本管理。draft 可編輯；發布(published) 後該版凍結（存檔被擋）。要修改已發布版本 → 另存新檔成新 draft。發布需 manager 以上權限。

        


        

          
⑥ 匯出

          
    
            
  • 預覽 / Excel：工序單；Excel 附 Level 欄（主序/角色/群組/巢狀母組/組內序/nb）→ 人看得懂關係。
    • 
            
  • lb-csv / lb-api：給 LB 的完整約束模型——含每節點允許主序集合（自由度）、sub/cub 群組語意、巢狀、nb 分站約束。
    • 
          

        


        

          
⑦ 使用者（權限 RBAC）

          
角色由低到高：viewer（只讀）＜ IE（編輯工時表/Level/詞彙）＜ manager（發布/凍結）＜ admin（管理使用者）。身分由閘道（Traefik/OAuth2）注入，本系統只管角色授權。右上角 👤 顯示目前身分。
